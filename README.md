# Skincare E-Commerce Platform

## Overview

This project is a full-stack skincare web application developed using Flask. The platform allows users to browse skincare products, manage accounts, and interact with an online shopping environment, while administrators can manage products and users through a dedicated dashboard.

---

## Features

### User Features

* User registration and login
* Secure authentication
* Password reset via email
* User profile management
* Product browsing
* Shopping cart functionality
* Search functionality
* Product categories
* New arrivals and special offers

### Admin Features

* Admin authentication
* Product management
* Add, edit, and delete products
* User management
* Role-based access control
* Database administration
